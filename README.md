# 하늘까지 탑 쌓기

블록을 쌓다가 초등 2학년 문제를 푸는 게임이에요.

- `index.html`: 게임 화면이에요.
- `questions.js`: 국어·통합교과·수학 문제 목록이에요. 문제를 바꿀 때는 이 파일만 고쳐요.

## 문제 한 줄 쓰는 법

```js
['국어', '‘높다’와 뜻이 반대인 말은?', ['낮다', '크다', '길다', '넓다'], '높다 ↔ 낮다'],
```

`[과목, 질문, [정답, 오답, 오답, 오답], 풀이, 보기(없으면 생략)]` 순서로 적어요. 정답은 항상 맨 앞에 두면 돼요. 게임에서 보기 순서는 자동으로 섞여요.
